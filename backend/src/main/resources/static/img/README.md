# 商品 / 供应商 图片放置说明

系统**优先加载真实照片**，缺图时自动回退到内置矢量图（`.svg`），不会出现裂图。

## 怎么放真实图（淘宝那种产品照）

把图片按 **id 命名**放进对应目录，扩展名用 `.jpg`（也支持 `.png` / `.webp`，
但需与数据库中路径扩展名一致，默认是 `.jpg`）：

- 商品照片 → `static/img/goods/<商品id>.jpg`
- 供应商图片 → `static/img/suppliers/<供应商id>.jpg`

放进去后重新打包 `mvn package`（或直接放到运行目录的静态资源下），刷新页面即可。
